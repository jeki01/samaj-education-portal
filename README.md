# Samaj Education Portal

Panchal Samaj 14 Chokhra — Education Portal

## Structure

```
samaj-education-portal/
├── admin-frontend/   # Admin panel (React + Vite)
└── user-frontend/    # User portal (React + Vite)
```

## Setup

### Admin Frontend
```bash
cd admin-frontend
yarn install
yarn dev
```

### User Frontend
```bash
cd user-frontend
yarn install
yarn dev
```
